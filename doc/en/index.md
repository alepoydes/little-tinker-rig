# PyBlocks Studio guide

PyBlocks Studio edits ordinary Python as visible structural blocks. The source
file remains readable and executable outside the editor. English and Russian
interfaces share the same editing operations; **View → Language** also selects
the language of this guide.

Start with [installation](INSTALL.md) and [first steps](tutorial/first.md).
For a practical project, build and run the [delivery robot](robotics.md#delivery-robot)
on a virtual Inventor / SPIKE Prime hub.

- [Create your own block library](snippets.md)

The **Block library** section in the help contents lists groups. Each group page
contains its blocks, parameter tables, and Python code. F1 opens the selected
block's section; the list at the top of the page jumps between blocks in the group.
Search includes every block's description and code.
