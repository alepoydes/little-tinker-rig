# Терминальная среда Python

TUI на Textual предназначен для исходников Python и работы с Pybricks. Блоков,
Scratch, уроков и 3D-сборки в нём нет. Опция `tui` не устанавливает Qt.

```sh
uv sync --locked --extra tui --extra pybricks
uv run --locked --extra tui --extra pybricks little-tinker-rig-tui examples/first.py --language ru
```

Для редактирования и виртуальных хабов достаточно `--extra tui`. Без имени файла
откроется новая программа. Язык можно переключить командой **Язык** из меню F10.
Требования к подключению и прошивке описаны в разделах [установка](INSTALL.md)
и [роботы](robotics.md).

## Редактирование и сохранение

Главную область занимает обычный редактор Python с подсветкой и номерами строк.
Tab добавляет отступ; Ctrl+Z / Ctrl+Y отменяют и возвращают правки. Ctrl+Space
вызывает автодополнение, F1 — сигнатуру и документацию через статический анализ Jedi.

| Клавиша | Действие |
| --- | --- |
| Ctrl+N / Ctrl+O | Новая программа / открыть |
| Ctrl+S | Сохранить |
| Ctrl+Shift+S | Сохранить как; также доступно через F10 |
| Ctrl+F / F3 | Поиск и замена / следующее совпадение |
| Escape | Закрыть поиск и вернуться к редактору |
| F10 | Меню команд, включая проверку синтаксиса и выбор языка |
| Ctrl+Q | Выход с предложением сохранить или отбросить изменения |

Сохранение сохраняет незаконченный код, комментарии, пробелы и окончания строк.
Старые файлы открываются в исходной кодировке; запись всегда использует UTF-8 без
BOM и обновляет объявление кодировки в редакторе. Это изменение можно отменить.
Импорты и вспомогательные функции блоков не
перестраиваются, метаданные `.ltr.json` не изменяются. Внешние изменения файла
защищены от случайной перезаписи: откройте файл заново либо сохраните свою версию
под другим именем.

## Подключение и запуск

F7 открывает подключение, если хаб отключён. Во время подключения F7 отменяет
попытку, после подключения — отключает хаб. По умолчанию выбран Bluetooth; доступны также USB и
виртуальные Inventor / SPIKE Prime, BOOST и Technic. Поле модели относится только
к виртуальным хабам. В строке состояния видны соединение и выполнение программы.

| Клавиша | Действие |
| --- | --- |
| F4 | Сохранить и загрузить без запуска |
| F5 | Сохранить, загрузить и запустить |
| F6 | Остановить программу или монитор |
| F8 | Показать или скрыть консоль |
| F9 | Открыть или закрыть монитор портов |

**Запустить загруженную программу** и **Отключить хаб** доступны через F10.
Загрузка требует корректного синтаксиса и успешного сохранения. Вывод и прогресс
передачи видны в консоли; индикатор показывает проценты, сообщаемые транспортом.
Для ошибки доступен переход к строке. Если исходник уже изменён, переход не
выполняется: ошибка относится к версии, которая была запущена.

Для физического хаба строка ввода в консоли отправляет текст по Enter во время
выполнения программы. Это ввод программы, а не Python REPL. Локальный виртуальный
хаб такой текстовый ввод не поддерживает.

Монитор включается явно. На физическом хабе он запускает служебную программу,
останавливая пользовательскую и иногда заменяя сохранённую. После мониторинга
загрузите свою программу заново. У виртуального хаба телеметрия работает в фоне;
панель показывает её данные.

## Установка прошивки

Выберите **Прошивка хаба** в F10. Укажите хаб и тип прошивки, обновите версии и
подготовьте загрузку либо введите путь к локальному ZIP/BIN. Кеш общий с Qt,
поэтому сохранённые пакеты можно использовать без повторного скачивания.

При подготовке проверяется пакет и показываются модель, версия, контрольная сумма
и лицензия. Следуйте инструкции входа в загрузчик, прочитайте лицензию и подтвердите
замену прошивки и программы. Приложение освободит соединение и запустит установщик
отдельным процессом. Диалог остаётся открытым до завершения и показывает результат.

Автоматическая загрузка оригинальной прошивки LEGO доступна только для
поддерживаемого образа Inventor / SPIKE Prime; другим поддерживаемым хабам нужен
подходящий локальный пакет восстановления. Чтения программы с хаба нет.
