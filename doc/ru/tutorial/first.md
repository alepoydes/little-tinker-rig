# Первые шаги

Программа — последовательность действий. LittleTinker Rig хранит её в обычном
файле Python и показывает структуру цветными блоками.

Откройте редактор через ярлык или как описано в разделе
[установка](../INSTALL.md), затем выберите **Файл → Примеры → first.py**.
Для повторного запуска не нужны параметры терминала.

Узкая панель иконок слева переключает рабочие режимы, в том числе **Программа**,
**Управление**, **Редактор блоков** и **Справка**. Наведите указатель на иконку,
чтобы увидеть её название. Библиотека показывает описания блоков и код Python.
Открытые файлы находятся во вкладках сверху. Две иконки справа вверху документа
переключают **Блоки / Python**; те же команды есть в меню **Вид**.
Если строка блока шире редактора, рядом появляются **← / →**. Они помогают
добраться до параметров дальше по строке и не меняют программу.
**Scratch** изначально скрыт: откройте его кнопкой внизу и перетаскивайте туда
блоки, которые хотите отложить. **Консоль** также открывается кнопкой внизу.

**Файл → Примеры** при первом открытии создаёт вашу рабочую копию вместе с
локальными модулями. Повторное открытие продолжает последнюю попытку, в том числе
после перезапуска. Изменения сохраняются автоматически. **Файл → Примеры → Начать
этот пример заново** создаёт другую попытку; **Мои попытки** открывает предыдущие.
**Сохранить как** сохраняет связь с примером и переносит модули в выбранную папку.

## С пустого документа

Выберите **Файл → Новый** для пустого документа. При первом запуске выбран
начальный уровень; затем выбор
запоминается. Выберите кнопку уровня **1** и представление **Каталог**, пользуясь
подсказками на иконках. Откройте категорию **Программа**.

1. Перетащите **Повторить со счётчиком** в пустую программу.
2. Нажмите на `10`, введите `3` и подтвердите Enter.
3. Перетащите **Вывести значение**, тоже из **Программы**, на `pass` внутри цикла.
   Действие заменит `pass` внутри цикла.
4. Замените `"Hello!"` своим сообщением в кавычках и подтвердите Enter.
5. Выберите **Подключить хаб → Виртуальный хаб → Robot Inventor / SPIKE Prime**
   и подтвердите подключение.
6. Нажмите **Запустить**, затем откройте **Консоль**. Сообщение появится три раза.
   Запуск использует текущий текст и не требует выбора имени файла.

Команда **Сохранить** позволяет выбрать имя и папку. Перед запуском создаётся
копия для восстановления после сбоя; обычные файлы при запуске не перезаписываются.
После первого сохранения редактор запоминает выбранный файл. Новый документ
не создаёт `main.py` или `untitled.py` в текущем каталоге без выбора имени.
Закройте его и откройте через **Файл → Открыть** или список недавних файлов.

## Изменить сообщение

Нажмите на сообщение в кавычках внутри своего блока `print(...)`. Введите
`"Привет, робот!"` вместе с кавычками и нажмите Enter. Если вы открыли
`examples/first.py`, вместо этого нажмите на `message` в `print(message)`.
Стрелка списка подсказок появляется только при наличии вариантов.

Enter, выбор подсказки и выход из поля применяют корректный ввод. Сохранение
и запуск также сначала применяют его. Escape отменяет правку. Некорректный ввод
остаётся видимым и редактируемым: исправьте или отмените его перед сохранением,
запуском или уходом из документа. **Стоп / F6** и отключение хаба остаются
доступными и сохраняют незавершённый ввод.

Кавычки означают строку. Слово без кавычек означает имя переменной. Число,
например `42`, пишется без кавычек. F3 открывает параметры выбранного блока.

## Добавить действие

Перетащите карточку из библиотеки в программу. Линия и предварительный код
показывают место вставки и вложенность. Отпустите карточку: блок сразу вставится
со значениями по умолчанию. Нажмите на поля параметров, чтобы изменить их.
Двойной щелчок по карточке вставляет действие в текущую позицию структурного выбора.

Перетаскивайте существующий блок, чтобы переместить его. Заливка и контур
показывают выделение. Правила Python сохраняются: например, `break` нельзя вынести
из цикла. Пустое тело цикла, условия или функции обозначается `pass`. Нажмите
эту строку перед двойным щелчком по карточке или перетащите блок на неё.

Чтобы добавить действие после последнего цикла, отпустите его в пустом месте
под программой. Перед отпусканием проверьте подсказку места вставки. Нижняя
половина последней строки тела цикла оставляет действие внутри цикла.

## Попробовать и отменить

**Ctrl+Z** отменяет последнее изменение, включая перенос между программой
и Scratch; **Ctrl+Shift+Z** возвращает отменённое изменение. Иконка Python
открывает текстовый редактор. Он допускает незавершённый текст и форматирует
корректный Python при сохранении, запуске, возврате к блокам или по Ctrl+Alt+L.
**F2 / Фрагмент Python** редактирует только выбранный фрагмент. Если результат
некорректен, диалог объясняет причину и остаётся открытым; исправьте или отмените
правку, чтобы вернуться к программе.

## Запустить без робота

Нажмите **Подключить хаб** справа вверху, выберите **Виртуальный хаб** и модель,
затем **F5 / Запустить**. Кнопка **Консоль** показывает появление новых сообщений.
**F6 / Стоп** прерывает программу, включая бесконечный цикл.

Для опытов с мотором откройте `examples/motor.py`. Для более сложного задания
используйте `examples/courier.py` и [руководство по роботу](../robotics.md).

## Отложить фрагмент

Откройте Scratch кнопкой внизу и перетащите туда действие. Оно останется
редактируемым в отдельной ячейке. Если тело цикла опустело, редактор оставит `pass`.
Сюда же можно перетаскивать заготовки из библиотеки.

Чтобы вернуть фрагмент, потяните за ручку ⠿ в его заголовке и отпустите у зелёной
линии в программе. Части ячейки перетаскиваются так же, как блоки программы.
Нужные импорты добавятся при возврате. **Ctrl+Z** отменяет весь перенос.
Иконка Python в ячейке позволяет дописать незавершённый текст.

## Сохранить

**Ctrl+S** сохраняет программу как `.py`. Scratch и настройки коллекций сохраняются
рядом в `имя.py.ltr.json`. Этот файл не нужен для запуска Python; переносите его
вместе с программой, если важны временные фрагменты и настройки редактора.
В блоковом режиме **Ctrl+X** переносит фрагмент в Scratch; в Python вырезает текст.

**Ctrl+O** открывает один или несколько файлов во вкладках сверху. Повторное
открытие выбирает существующую вкладку и сохраняет её правки. Переключение вкладок
сохраняет режим, черновик, прокрутку и историю отмены. **Ctrl+N** создаёт новый файл,
**Ctrl+W** закрывает текущую вкладку. При закрытии можно сохранить, отбросить
правки или отменить закрытие.

Если файл изменён внешним редактором, сохранение предлагает **Перечитать
с диска**, **Сохранить копию…** или отмену. Перезагрузка заменяет открытый вариант;
обычное открытие лишь выбирает его вкладку.

Сохранить можно и незавершённый Python. Перед запуском или переходом к блокам
исправьте синтаксис. После аварийного завершения редактор предлагает восстановить
вкладки, несохранённый текст и Scratch. Ошибка выполнения показывает объяснение
и кнопку **Показать блок** в консоли; если программу уже изменили, открывается
запущенный текст только для чтения. Подробнее — [редактирование и восстановление](../usage.md).
