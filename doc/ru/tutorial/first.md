# Первое знакомство

Программа — последовательность действий, которую выполняет компьютер или хаб.
В LittleTinker Rig она записана обычным текстом Python. Редактор показывает структуру
цветными областями и помогает менять её целыми фрагментами.

Откройте пример:

```sh
uv run --extra qt little-tinker-rig-qt examples/first.py
```

В узкой полосе слева находятся вертикальные переключатели **Программа**,
**Управление**, **Помощь**. **Вид → Язык** меняет язык интерфейса и справки.
В режиме программы библиотека готовых действий расположена рядом с кодом.
Карточки показывают цвет блока, его назначение и Python. **Черновики / Scratch**
видны справа: сюда можно отложить блоки перетаскиванием. **Консоль** открывается
кнопкой внизу окна.

Меню **Файл → Примеры** открывает сами файлы примеров. Перед изменениями
используйте **Сохранить как**, чтобы оставить свою отдельную версию.

## С пустого документа

Запустите `uv run --extra qt little-tinker-rig-qt` без имени файла или выберите
**Файл → Новый**. Выбран начальный уровень; откройте категорию **Программа**.

1. Перетащите блок повторения со счётчиком в пустую программу.
2. Нажмите на `10`, введите `3` и подтвердите Enter.
3. Перетащите блок вывода в консоль из категории **Свет и звук** на `pass` внутри цикла.
   Он заменит `pass` внутри цикла.
4. Замените `"Hello!"` своим сообщением в кавычках и подтвердите Enter.
5. Выберите **Подключить хаб → Виртуальный хаб → Robot Inventor / SPIKE Prime**
   и подтвердите подключение.
6. Нажмите **Запустить**, выберите имя и папку для программы, затем откройте
   **Консоль**. Сообщение появится три раза. Отмена сохранения отменяет и запуск.

После первого сохранения редактор запоминает выбранный файл. Новый документ
не создаёт `main.py` или `untitled.py` в текущем каталоге без выбора имени.
Закройте его и откройте через **Файл → Открыть** или список недавних файлов.

## Изменить сообщение

1. Найдите в программе `print(message)`: параметр `message` показан светлым полем
   со стрелкой раскрытия.
2. Нажмите на это поле. Можно выбрать доступное имя или ввести своё выражение.
3. Введите `"Привет!"` вместе с кавычками и подтвердите изменение.
4. В программе появится `print("Привет!")`.

Кавычки означают текст. `message` без кавычек означает имя, под которым ранее
сохранено значение. Число, например `42`, пишется без кавычек.

Для запуска этого обычного примера на компьютере сохраните его и выполните:

```sh
uv run python examples/first.py
```

Можно выполнить пример прямо в редакторе: нажмите **Подключить хаб**, выберите
**Виртуальный хаб**, подтвердите и нажмите **F5 / Запустить**. Кнопка **Консоль**
покажет, что появились сообщения. Откройте её, чтобы увидеть результат.
**F6 / Стоп** прерывает программу. Для проверки мотора откройте
`examples/motor.py`; подробности — [робот и управление](../robotics.md).

## Добавить действие

Выберите строку, после которой нужно вставить действие. В библиотеке откройте
**Свет и звук** и дважды нажмите карточку вывода в консоль. Сразу появится `print("Hello!")`.
Нажмите на поле `"Hello!"` и замените значение, например на `123`.
Редактор приведёт отступы в порядок; дополнительного окна после вставки нет.

Сниппет также можно перетащить из Library в программу. Линия показывает место
вставки, а рядом виден предварительный код с параметрами по умолчанию.
Пустое тело цикла, условия или функции обозначается `pass`. Нажмите на эту строку
перед двойным щелчком по карточке либо перетащите блок на неё: он заменит заглушку.

## Попробовать и отменить

**F2 / Фрагмент Python** открывает выбранный фрагмент для текстового редактирования.
Можно временно написать незаконченный код. Если Python не принимает результат,
диалог покажет причину и останется открытым. Основная программа ещё не изменена.
Исправьте текст или отмените. Две маленькие кнопки справа вверху документа
переключают **Блоки / Python**. Те же команды есть в меню **Вид**.
Python-режим позволяет редактировать весь файл; код форматируется при сохранении
и переходе обратно к блокам.

**Ctrl+Z** отменяет последнее изменение, включая перенос между программой
и Scratch. В Qt **Ctrl+Shift+Z**, в TUI **Ctrl+Y** возвращает отменённое изменение.

## Отложить фрагмент

Перетащите действие из программы в панель Scratch справа. Оно останется видимым
и редактируемым в отдельной ячейке. Если тело цикла опустело, редактор оставит
`pass`. Сюда же можно перетаскивать заготовки из библиотеки.

Чтобы вернуть фрагмент, потяните за ручку ⠿ в его заголовке и отпустите у зелёной
линии в программе. Части ячейки перетаскиваются так же, как блоки программы.
Нужные импорты добавятся при возврате. **Ctrl+Z** отменяет весь перенос.

Иконка Python в ячейке позволяет дописать произвольный незаконченный текст.
Панель можно растянуть или закрыть; кнопка Scratch внизу открывает её снова.

## Сохранить

**Ctrl+S** сохраняет программу как `.py`. Scratch сохраняется рядом в файле
`имя.py.ltr.json`. Этот дополнительный файл не нужен для запуска Python,
но его нужно переносить вместе с программой, если важны временные фрагменты.

**Ctrl+O** открывает один или несколько файлов во вкладках сверху. Каждый файл
сохраняет свой режим, черновик и историю отмены. **Ctrl+N** создаёт новый файл,
**Ctrl+W** закрывает текущую вкладку. Точка перед именем означает несохранённую
правку. При закрытии можно сохранить, отбросить правки или отменить закрытие.

Программу можно открыть в любом текстовом редакторе. Если её изменить там,
LittleTinker Rig при следующем открытии заново построит структуру. Если файл изменён
внешним редактором уже после открытия, сохранение остановится с сообщением
о конфликте: откройте актуальную версию или сохраните свою под другим именем.

Сохранить можно и незавершённый Python. Перед запуском или переходом к блокам
исправьте синтаксис. После аварийного завершения редактор предлагает восстановить
вкладки, несохранённый текст и Scratch. Ошибка выполнения показывает объяснение
и кнопку **Показать блок** в консоли; если программу уже изменили, открывается
запущенный текст только для чтения.

Меню **Примеры** открывает файлы из `examples/` и подпапок. Для собственного
варианта примера используйте **Сохранить как**.
