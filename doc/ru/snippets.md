# Авторская библиотека сниппетов

Библиотека — каталог с `collection.toml` и обычными `.py`-файлами. Загрузчик читает
исходники через AST: импорты, декораторы и тела функций не исполняются.

```text
my_snippets/
    collection.toml
    motors.py
    history/
        1.0.0/
            motors.py
```

Минимальный `collection.toml`:

```toml
[collection]
id = "course"
version = "1.1.0"

[[history]]
version = "1.0.0"
path = "history/1.0.0"
```

Историческая секция необязательна. Каждый модуль группирует записи в Library.
Идентификатор функции `turn` в `motors.py`: `course/motors/turn`.

## Определение шаблона

```python
def turn(motor: "Motor", speed: "deg/s" = 300, angle: "deg" = 90):
    """Повернуть мотор на заданный угол и дождаться завершения."""
    motor.run_angle(speed, angle)
```

Параметры — подставляемые Python-выражения, значения по умолчанию — начальные
выражения, docstring — справка. Строковые аннотации дают единицы или вид объекта.
Если тело состоит из единственного `return`, шаблон представляет выражение:

```python
def below(sensor, threshold: "%" = 30):
    """Проверить отражение относительно порога."""
    return sensor.reflection() < threshold
```

Импорты в непосредственном теле функции объявляют зависимости. При вставке
они попадают в управляемый заголовок программы. Пользовательские импорты
снаружи этой секции сохраняются. Совпадающие имена из разных импортов вызывают
явную ошибку; редактор не переопределяет пользовательскую переменную молча.

## Семантика подстановки

Шаблон разворачивается в код, а не вызывается как функция. Если параметр
встречается дважды, подставленное выражение также выполняется дважды.
Например, `return x + x` с `x=read_sensor()` даёт два чтения датчика.
Если нужен один замер, сохраните его во внутреннюю переменную шаблона.

В позиции присваивания параметр должен быть допустимой целью Python, например
именем `motor`. Редактор проверяет готовую программу до фиксации изменения.
Внутренние переменные при конфликте получают свободное имя `error_2` и далее.
Распознавание допускает такое согласованное переименование.

Пока не поддерживаются рекурсивные определения, декораторы шаблонов,
`*args`/`**kwargs`, объявления `global`/`nonlocal` внутри шаблона.
Классы следует вынести в обычный вспомогательный модуль: имена их атрибутов
являются публичным интерфейсом, и переименовывать их как локальные переменные
нельзя. Вложенные функции и comprehension имеют отдельные лексические области.
Вложенный импорт вида `import a.b` требует явного `as`.
Сниппеты не являются системой произвольных исполняемых макросов.

## Распознавание и обновление

Распознавание сравнивает структуру AST. Повторные использования параметра должны
соответствовать одному выражению. Многострочный шаблон совпадает с непрерывной
частью одного тела Python-конструкции. Комментарии не влияют на распознавание.

Текущая форма сниппета исключает его исторические формы в той же области.
Среди остальных совпадений предпочитается большая область, затем большее число
фиксированных AST-узлов, затем текущая версия. Последняя развязка —
лексикографический идентификатор. Общий шаблон отдельного вызова не должен
скрывать старую форму целого алгоритма. Пересекающиеся совпадения не
отображаются как независимые составные блоки.

Для автоматического обновления старые параметры должны остаться с теми же
значениями и смыслом. Новые параметры должны иметь значения по умолчанию.
Смена основной версии или вида «инструкции / выражение» требует ручного
редактирования. Редактор может проверить совместимость формы сигнатуры;
сохранение предметного смысла — ответственность автора библиотеки.
Комментарии обновляемой области сохраняются перед новым телом: после изменения
алгоритма невозможно автоматически гарантировать их привязку к прежней инструкции.

Workspace-файл может закрепить версию коллекции через `"pins": {"course": "1.1.0"}`.
При несовпадении редактор сообщает ошибку. Установите соответствующую библиотеку
или явно измените закрепление. Меток отдельных блоков в `.py` нет.

## Типы и встроенная библиотека

Аннотация результата выражения (`-> "bool"`, `-> "mm"`) задаёт тип подсказки.
Типы параметров и возвращаемых значений читаются статически. Числовые единицы
относятся к числовому типу; редактор не преобразует единицы автоматически.
Известный тип получателя различает `motor.brake()` и `drive.brake()`.
Неизвестные динамические значения остаются обычным Python.

Встроенная библиотека содержит создание моторов, направление, скорость,
перемещение по углу и времени, чтение угла; DriveBase; цвет, отражение,
ультразвуковое расстояние, датчик силы, комбинированный датчик BOOST;
ожидание и секундомер; переменные, сравнения, логические операции и циклы.
Порт — Python-выражение `Port.A`, без кавычек. Полное определение устройства
распознаётся одним блоком. Scratch использует эти же шаблоны без добавления импортов.

Для датчика BOOST расстояние выражается в процентах относительной дальности;
ультразвуковой датчик возвращает миллиметры. См. [API датчика BOOST](https://docs.pybricks.com/en/latest/pupdevices/colordistancesensor.html)
и [API UltrasonicSensor](https://docs.pybricks.com/en/latest/pupdevices/ultrasonicsensor.html).


## Группы и страницы справки

Модуль задаёт группу: `collection/motors.py` образует `collection/motors`.
Выносите самостоятельные темы в отдельные модули. Библиотека и справка
используют эти группы; исторические шаблоны не попадают в видимый список.
У встроенных групп переведены заголовки, у дополнительных коллекций заголовком
служит идентификатор модуля. Все блоки группы показаны на одной странице справки.
Английский docstring — исходное описание; переводы берутся из каталога интерфейса.
F1 открывает устойчивый раздел выбранного блока внутри страницы группы.

## Уровни сложности

Манифест коллекции задаёт каждому блоку один уровень: `beginner`, `standard` или
`expert`. Если уровень не указан, используется `standard`. Неизвестные имена
блоков и уровни отклоняются. Значение `all` существует только в фильтре библиотеки.
Карточки библиотеки и справка используют одни метаданные. Уровень указывает,
когда вводится блок; фильтры накопительные. Начальный набор должен оставаться
небольшим. При добавлении блоков учитывайте [учебные уровни](learning.md).

```toml
[levels]
"motors/move_for" = "beginner"
```

Аннотация шаблона `-> "statement"` сохраняет `return` как оператор, вместо
превращения его значения в шаблон выражения. Так реализован блок возврата,
допустимый в теле функции и в отдельном фрагменте Scratch. Шаблон `-> "loop"`
содержит одну оболочку `while`, при вставке остаётся только её тело. Так шаблоны
`break` и `continue` остаются компилируемым Python, а вставка проверяет контекст
цикла в месте назначения. Остальные аннотации
сохраняют прежний смысл типа выражения. Редактирование списков переменной длины
опирается на развёрнутый вызов, определение или логическое выражение Python;
сама функция шаблона по-прежнему объявляет фиксированный набор подстановок.

Подсказки типов параметров допускают простые альтернативы, например
`"ColorSensor | ColorDistanceSensor"`. Распознавание, предложения имён и типы
результатов методов используют один набор альтернатив без выполнения аннотаций.
Это удобно для общих операций датчиков; разные единицы остаются раздельными:
расстояние BOOST измеряется в процентах, ультразвуковое — в миллиметрах.
