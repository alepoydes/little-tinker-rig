# Руководство LittleTinker Rig

[Уроки, проекты ученика и сборка робота](lessons.md)

LittleTinker Rig позволяет редактировать обычный Python как видимые структурные
блоки. Исходный файл остаётся читаемым и исполняемым вне редактора. Английский
и русский интерфейсы используют одинаковые операции; **Вид → Язык** также
выбирает язык этого руководства.

Начните с [установки](INSTALL.md). Запуск без имени файла открывает страницу
**Начало**: можно продолжить работу, создать программу или пройти урок
**Первая программа на Python** без настоящего робота. Значок **Начало** возвращает
сюда, не закрывая файлы. Подробности — в [первом знакомстве](tutorial/first.md).
Практический пример — [робот-курьер](robotics.md#робот-курьер), которого можно
собрать и запустить на виртуальном Inventor / SPIKE Prime.

Раздел **Библиотека блоков** в оглавлении справки содержит группы. Страница группы
показывает все её блоки, таблицы параметров и Python-код. F1 открывает раздел
выбранного блока; список в начале страницы позволяет переходить между блоками
группы. Поиск учитывает описание и код каждого блока.
