# Установка и первый запуск

LittleTinker Rig работает на компьютере. Для редактора и виртуальных хабов робот
не нужен. Настоящему хабу требуется подходящая прошивка Pybricks. Начните с
виртуального хаба; [подключение робота](robotics.md) и [помощь с USB](usb.md)
описаны отдельно. Запуск через ярлык Windows и работа с физическим оборудованием
пока не проверены вручную на этой платформе.

## Установить редактор один раз

Установите [Git](https://git-scm.com/downloads) и
[uv](https://docs.astral.sh/uv/getting-started/installation/). В Windows откройте
PowerShell и, если доступен WinGet, выполните:

```powershell
winget install --id Git.Git -e --source winget
winget install --id astral-sh.uv -e --source winget
```

Если WinGet недоступен, воспользуйтесь установщиками по ссылкам. После установки
закройте и снова откройте PowerShell, чтобы он нашёл `git` и `uv`. В Linux или
macOS установите их по ссылкам либо через пакетный менеджер. Затем откройте
терминал в папке, где хотите хранить проект, и выполните:

```sh
git clone https://github.com/alepoydes/little-tinker-rig.git
cd little-tinker-rig
uv sync --locked --no-dev --extra qt
```

Не перемещайте папку проекта после установки: редактор использует её. `uv`
создаёт отдельное окружение `.venv` и при необходимости скачивает версию Python
из `.python-version`; активировать окружение не нужно. Проект поддерживает
Python 3.11+, а в этой версии исходников использует 3.13. `--locked` сохраняет
записанные версии зависимостей, `--no-dev` исключает инструменты разработки,
а `--extra qt` устанавливает графический редактор. Эти параметры нужны при
установке, а не при каждом запуске.

## Открывать редактор каждый день

В Windows откройте файл `little-tinker-rig-qt.exe` в папке
`.venv\Scripts` проекта двойным щелчком либо выполните в PowerShell из папки
проекта:

```powershell
.\.venv\Scripts\little-tinker-rig-qt.exe
```

Для удобного запуска щёлкните по `.exe` правой кнопкой в Проводнике, создайте
ярлык (при необходимости откройте **Показать дополнительные параметры**) и
перенесите ярлык на рабочий стол. Саму папку проекта оставьте на месте.
В Linux и macOS запускайте из папки проекта:

```sh
./.venv/bin/little-tinker-rig-qt
```

При первом запуске на странице **Начало** показан урок **Первая программа на
Python** с рисунком и тремя заданиями. Откройте его карточку, измените сообщение
и число повторов, затем нажмите **Подключить хаб**, оставьте выбранными
**Виртуальный хаб** и **Robot Inventor / SPIKE Prime**, нажмите **Подключить**,
а затем **F5 / Запуск**. Результат виден
в **Консоли**. Настоящий робот не нужен. Кнопка **Новая программа** открывает
пустой документ, **Открыть файл…** — прежнюю работу. Значок **Начало** возвращает
на стартовую страницу, не закрывая файлы. Повторное открытие карточки урока
продолжает последнюю попытку. При запуске редактора имя файла указывать не нужно.

Изначально интерфейс английский. Выберите **View → Language → Русский**;
настройка и язык встроенной справки сохранятся. Продолжение — в разделе
[первые шаги](tutorial/first.md).

## Добавить настоящий хаб или геймпад позже

Для Bluetooth и поддерживаемых USB-подключений один раз выполните из папки
проекта:

```sh
uv sync --locked --no-dev --extra qt --extra pybricks
```

Тот же ярлык редактора теперь открывает программу с инструментами хаба; параметры
при запуске не нужны. Установится закреплённая версия
[форка pybricksdev](https://github.com/alepoydes/pybricksdev). Для физического
геймпада добавьте `--extra gamepad` к команде установки. Когда добавляете
возможность или обновляете проект, повторяйте `uv sync` со *всеми* нужными
опциями: синхронизация без ранее выбранной опции может удалить её из `.venv`.

Настоящему хабу нужна подходящая прошивка Pybricks. Стабильная версия 4.0.1 на
Inventor/Prime использует Bluetooth; USB Serial требует совместимой бета-версии.
Выберите свою модель в [руководстве по роботам](robotics.md), а порт и прошивку
проверьте по [помощи с USB](usb.md). USB-поддержка EV3 экспериментальна и не
проверена на оборудовании.

Для терминального редактора см. [руководство TUI](tui.md): опция `tui`
устанавливается один раз, затем программа запускается из `.venv` в терминале.

## Если запуск не удался

- Если терминал не находит `git` или `uv` после установки, откройте новый
  терминал и проверьте `git --version` или `uv --version`.
- Если графический редактор не открывается в Windows, запустите
  `.\.venv\Scripts\little-tinker-rig-qt-console.exe` из PowerShell, чтобы
  увидеть ошибку запуска. В Linux/macOS запустите программу из терминала.
- Если отсутствует дополнительный пакет, повторите `uv sync` с нужными
  опциями. Для `PySide6` нужна `qt`, для `pybricksdev` — `pybricks`.
- Если Qt не может открыть экран, проверьте графическую сессию и драйвер;
  без графического окружения используйте [TUI](tui.md). Если не работает только
  3D, текстовые шаги сборки и список деталей остаются доступны.
- Если настоящий хаб не находится или порт занят, закройте другие программы
  для хаба и проверьте Bluetooth либо кабель и порт по [помощи с USB](usb.md).

Новая установка хранит настройки, проекты ученика и загрузки в пользовательских
папках ОС. Прежние настройки PyBlocks, проекты `.pyblocks` и рабочие файлы
`.pyblocks.json` остаются доступны; новые проекты уроков используют `.ltr`.
