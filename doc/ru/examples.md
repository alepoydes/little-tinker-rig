# Программы наборов LEGO в виде блоков

В проект включены все 37 файлов Python для поддерживаемых семейств хабов из официального
[репозитория Pybricks Projects](https://github.com/pybricks/pybricks-projects).
С вариантом управления Technic 42109 с Xbox и 15 программами сообщества
в каталоге 53 файла Python. На программы, доступные только на сайте, оставлены ссылки.
Откройте файл через **Файл → Примеры → pybricks** или **Файл → Открыть**. Выберите **Все**
в библиотеке, чтобы найти каждый использованный компонент. Фильтр уровня
ограничивает новые варианты, но не блоки уже открытого документа.

| Файл | Робот и подключения | Поведение |
|---|---|---|
| `boost_17101_auto_builder.py` | BOOST Auto Builder: конвейер B, рука D | Калибрует механизмы, собирает пять деталей и выдаёт результат |
| `inventor_51515_tricky.py` | Robot Inventor Tricky: колёса A/B, ультразвуковой датчик D | Включает глаза и поворачивается в обе стороны при объекте ближе 100 мм |
| `spike_45678_cnc.py` | SPIKE Prime CNC: горизонтальный мотор A, вертикальный C | Рисует прямоугольник и возвращает оси в начальное положение |
| `spike_45678_grabber.py` | Захват SPIKE Prime: мотор A, датчик силы E | Закрывается при нажатии, открывается до упора при отпускании |
| `spike_45678_kiki.py` | SPIKE Prime Kiki: датчик цвета B | Показывает небо, дом или траву для синего, жёлтого и зелёного объектов |
| `technic_42124_buggy.py` | Technic 42124: привод A, руль B, пульт LEGO | Центрирует руль и едет по командам пульта |
| `technic_42099_off_roader.py` | Technic 42099: передний привод A, задний B, руль C | Калибрует руль и проходит маршрут с заданными временами движения |
| `technic_42099_off_roader_remote.py` | Те же подключения 42099, пульт LEGO | Управляет двумя ведущими осями и рулём с пульта |

Направления моторов, размеры и настройки относятся к конкретным сборкам LEGO.
Одной замены портов недостаточно для переноса программы на другой механизм.

## Technic 42109 с Xbox

Откройте [technic_42109_xbox.py](../../examples/pybricks/technic_42109_xbox.py) через
**Файл → Примеры → pybricks**. Программа использует стандартные блоки продвинутого
уровня: рулевой мотор B, привод D, автоматическую калибровку руля, управление
левым стиком и курками. Правый курок задаёт движение вперёд, левый — назад.
Между обновлениями цикл ждёт 50 мс. Для калибровки нужны механические упоры
собранной машины; сопряжение контроллера виртуальный хаб не моделирует.

Нужны Pybricks 3.5+ и совместимый Bluetooth-контроллер Xbox. При первом подключении
включите контроллер и удерживайте кнопку сопряжения до частого мигания, затем
запустите программу. В дальнейшем достаточно включить контроллер.
Technic отключается от компьютера, чтобы подключиться к Xbox. **Для остановки
нажмите зелёную кнопку хаба**, затем снова подключите LittleTinker Rig для редактирования.
Подробнее — в [инструкции Pybricks](https://pybricks.com/project/technic-42109-xbox/).

## Экскаватор Technic 42100 с Xbox

Откройте два файла в **Файл → Примеры → pybricks → community**.
Нужны **Pybricks 4.0+ на обоих Technic-хабах** и Bluetooth-контроллер Xbox:

| Программа | Хаб и исходное подключение моторов |
|---|---|
| [technic_42100_base_xbox.py](../../examples/pybricks/community/technic_42100_base_xbox.py) | Нижний: A — левая гусеница, B — правая, D — поворот платформы |
| [technic_42100_upper.py](../../examples/pybricks/community/technic_42100_upper.py) | Верхний: A — стрела, B — рукоять, C — наклон ковша, D — открытие ковша |

Загрузите каждый файл на соответствующий хаб. Программы работают отдельно и не
импортируют друг друга. Выполните сопряжение Xbox, как описано выше, запустите
сохранённую программу нижнего хаба, затем верхнего; органы управления должны быть
отпущены. Нижний хаб светится синим при подключении, зелёным при работе и жёлтым
в медленном режиме. Верхний светится жёлтым в ожидании и зелёным при получении
свежих команд. Верхний можно запустить первым — он дождётся команд.
Для подключения Xbox нижний хаб отключается от LittleTinker Rig.

| Управление Xbox | Действие |
|---|---|
| LT / RT | Левая / правая гусеница вперёд |
| LB / RB | Левая / правая гусеница назад |
| Крестовина влево / вправо | Поворот платформы |
| Левый стик по вертикали | Движение стрелы |
| Правый стик по вертикали / горизонтали | Движение рукояти / наклон ковша |
| A / B | Открыть / закрыть ковш |
| Удерживать X | Медленный режим: 40% от заданных скоростей |
| Y | Завершить нижнюю программу; верхние моторы остановятся по тайм-ауту |

Отпустите управление для торможения. Одновременное нажатие противоположных
направлений также тормозит механизм. Зелёная кнопка каждого хаба останавливает
его программу. Остановка только верхнего хаба не останавливает основание.
Перед повторным подключением LittleTinker Rig остановите нижнюю программу.

Пауза в циклах — 50 мс. Номер радиопакета меняется при каждом обновлении, поэтому
повторение старой команды не поддерживает движение бесконечно: верхний хаб
тормозит через 500 мс без обновления, проверяя это каждые 50 мс.
При обнаружении отключения Xbox или нажатия Y основание останавливается и
передача прекращается; верхние моторы остановятся за время тайм-аута плюс один
интервал проверки. Обе программы используют канал 100; для соседнего экскаватора
выберите другой канал, изменив его в обоих файлах.

Скорости задаются в `track_speed`, `turn_speed` и верхнем `maximum_speeds`
(градусы в секунду на валу мотора); `slow_percent` определяет замедление по X.
Начальные значения скоростей и направления нужно проверить на собранной модели.
Начните с удерживания X и двигайте по одному механизму. Калибровки и определения
конца хода нет: на предельных положениях отпускайте управление.
Тесты используют виртуальные моторы и заданные входы радио/контроллера;
интерактивный симулятор не моделирует сопряжение Xbox и радиообмен хабов.
На физической модели программы пока не проверены.
[Источники и технические подробности](../../examples/pybricks/community/README.md).

## Полезные действия по уровням

[Каталог ссылок на проекты](../../examples/pybricks/website/README.md) ведёт к
внешним программам с пультом и Xbox для 42099, 42109, 42124, 42129, 42131,
42146 и 42160, балансир Inventor/SPIKE на шаре, меню хаба и небольшие задания
с вводом и моторами. Кран требует двух Technic-хабов и Pybricks 4: программы
основания и стрелы запускаются на разных хабах. Проекты с камерой требуют
внешней обработки изображения в Pybricks Code; LittleTinker Rig её не выполняет.
Эти программы не включены в поставку; требования перечислены рядом со ссылками. SPIKE Essential, Duplo и EV3 остаются
вне текущего набора поддерживаемых хабов. Начальная палитра не расширена;
задачи, радио и обмен с внешним приложением находятся на экспертном уровне.

Уровень **Начинающий** дополнен четырьмя готовыми действиями: перенести деталь
конвейера, нарисовать прямоугольник, повернуться в одну сторону и обратно,
управлять захватом по нажатию. Это обычные фрагменты Python, которые распознаются
в примерах и отдельно доступны в группе **Задания для робота**. В начальной
палитре теперь двадцать блоков.

**Средний** добавляет калибровку до упора с ограничением мощности, центрирование
руля по измеренным упорам, остановку накатом, яркость глаз ультразвукового датчика
и очистку экрана. Для калибровки нужен физический упор: сброс угла сам по себе
не определяет положение механизма.

**Продвинутый** открывает чтение угла при остановке об упор, режимы удержания
и наката, движение к цели без ожидания, ограничение ускорения, профиль точности
мотора, однократное чтение всех кнопок пульта и собственные рисунки экрана.
Для готовых значков остаётся более простой блок. Новые действия находятся в
соответствующих группах моторов, датчиков, хаба и пульта; справка берётся из тех
же определений.

Раскройте готовое действие, чтобы изучить и изменить отдельные команды. Исходник
виден и тогда, когда действие считается одним блоком. Раскрытие меняет режим
редактирования, а не программу; после изменения исходника распознавание повторяется.
Калибровку и настройки регулятора мотора можно изучать после запуска готового действия.

## Поведение и симуляция

В непосредственно перенесённых примерах сохранены исходные алгоритмы и существенные для механики детали: движение без
ожидания остаётся таким же; `run(0)` не заменяется торможением; захват завершает
открывание до следующей проверки нажатия. Программы пульта работают до команды
**Стоп**, выход по центральной кнопке в них не добавлен. В Kiki используется
нынешнее имя `display.icon()` с исходными рисунками пикселей.

Для полностью виртуального примера откройте `spike_45678_cnc.py`, подключите виртуальный
Inventor/Prime и настройте A и C как моторы. Tricky также работает виртуально
с моторами A/B и ультразвуковым датчиком D: уменьшите расстояние ниже 100 мм,
чтобы запустить танец. Яркость глаз и содержимое экрана выводятся в консоль.

Auto Builder, захват и калибровка руля требуют настоящих механических упоров.
Подключение пульта и профили точности моторов не реализованы в интерактивном
симуляторе. Синие, жёлтые и зелёные объекты Kiki задаются сценарием в тестах;
интерактивный виртуальный датчик пока сообщает только чёрный или белый цвет.
Тесты используют движение виртуальных моторов и явно заданные входы аппаратуры
для сравнения полных последовательностей команд; физическая сборка ими не проверяется.

В таблице выше перечислены восемь вводных заданий. [Полный каталог](../../examples/pybricks/README.md)
также содержит BOOST R2-D2 (75253), Inventor Blast/MVP/Gelo, исследовательский
ровер, балансирующего робота, сортировщик блоков, мини-погрузчик, Steerbot,
справочник API и все программы Technic с клавиатурой, пультом и Xbox из
зафиксированной версии исходников. EV3 не включён.

Храните файлы Gelo вместе: при отправке и запуске компилируется и локальный
модуль `inventor_51515_gelo.py`. Файл REPL предназначен для интерактивной работы,
а справочник API — для изучения по разделам. Имена файлов содержат номера наборов.
В каталоге указаны зависимости, дополнительное оборудование, оригинальные
исходники и объём проверки каждого файла.

На продвинутом уровне добавлены клавиатура, Xbox, измерение цвета и передачи.
Экспертный уровень раскрывает настройку регуляторов, дисплей, измерения хаба,
классы, контексты и генераторы. В обычном вызове функции можно менять вызываемую
функцию и список аргументов; это относится и к методам собственных классов роботов.
Начальная палитра по-прежнему содержит двадцать блоков.

Все файлы каталога компилируются для обоих ABI MPY и восстанавливаются из распознанных
блоков без изменения исполняемой структуры. Полная симуляция походки,
балансирования и опрокидывания не реализована. Тесты Xbox проверяют опрос входов,
порты моторов и паузы цикла. Совместимые помощники сохраняют
неблокирующий ввод с клавиатуры и старое правило знаков дуги. Исправлены
отсутствующий импорт const у Gelo и создание хаба у Audi.
Атрибуция исходников сохранена в `examples/pybricks/LICENSE.txt`.

Пять заданий с движением используют левый мотор **A против часовой стрелки**,
правый **B по часовой**, **колёса 56 мм** и **колею 112 мм**. Укажите реальные
размеры вашей сборки. Ультразвуковой датчик **C** смотрит вперёд для объезда и
следования за объектом, вправо для движения вдоль стены. Для остановки на красном
нужен датчик цвета **C**, направленный вниз. При старте задания с гироскопом хаб
должен лежать ровно и неподвижно. Следование прекращается при отсутствии замера
и возобновляется после его восстановления; скорость и поворот ограничены.

Примеры параллельных задач требуют моторов **A/B** (параллельное движение), **A**
(таймаут) или **A и ультразвукового датчика C** (препятствие/таймер). Последний —
демонстрация с одним мотором. Асинхронные программы запускайте на настоящем хабе:
интерактивный симулятор не реализует полноценный планировщик задач. В проверках
эта граница задаётся сценарием явно.

В трёх программах Xbox **RT едет вперёд, LT назад**, левый стик поворачивает,
**B завершает программу**. У шасси с рукой **C — левый мотор по часовой,
D — правый против часовой, E — рука**; **A** опускает руку, отпускание поднимает.
Перед стартом поднимите руку. У машины с подъёмником **B — руль, D — тяга,
E — подъёмник**, всё по часовой. Перед стартом выровняйте колёса. **Y** меняет
режим один раз за нажатие; в режиме подъёмника им управляет вертикальная ось
стика. Неактивные механизмы тормозят. У боксёра **A — левый мотор против часовой,
B — правый, C/D — руки по часовой**; перед стартом руки в исходном положении.
**LB/RB** дают удары, **A** — защиту. Одно нажатие вызывает одно действие,
через 500 мс подаётся команда возврата; управление движением не блокируется.
Для SPIKE 45678 потребуется четвёртый мотор. Автоматической калибровки нет;
углы валов и передачи должны соответствовать сборке.

Для новых программ **42100 с LEGO-пультами** нужны **два Powered Up 88010**,
по одному на хаб. Снизу A/B — гусеницы, D — поворот платформы; сверху A/B —
стрела/рукоять, C/D — ковш. Сопрягайте пары по очереди. Левая красная кнопка
выбирает A/B, правая — вторую группу. Клавиши ± управляют её моторами, центральная
кнопка завершает программу только своего хаба. Начальная мощность 40%, неактивные
группы тормозят. Сохранены исходные направления по часовой; автор обозначил эту
схему как **экспериментальную и не проверенную на настоящем 42100**. Проверьте
направления и пределы хода перед использованием. Хабы работают независимо,
радиопротокол варианта с Xbox здесь не используется.
