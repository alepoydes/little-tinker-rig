# Первое знакомство

Программа — последовательность действий, которую выполняет компьютер или хаб.
В PyBlocks она записана обычным текстом Python. Редактор показывает структуру
цветными областями и помогает менять её целыми фрагментами.

Откройте пример:

```sh
uv run --extra qt pyblocks-qt examples/first.py
```

Слева находится **Library** — библиотека готовых действий. В центре — программа.
Справа — **Scratch**, место для временных фрагментов и незаконченных идей.
Внизу — **Console**, куда поступают сообщения редактора и подключённого хаба.

## Изменить сообщение

1. Выберите в программе `print(message)`.
2. Нажмите **F3 / Parameters**. Поле `value` задаёт, что нужно показать.
3. Введите `"Привет!"` вместе с кавычками и подтвердите изменение.
4. В программе появится `print("Привет!")`.

Кавычки означают текст. `message` без кавычек означает имя, под которым ранее
сохранено значение. Число, например `42`, пишется без кавычек.

Для запуска этого обычного примера на компьютере сохраните его и выполните:

```sh
uv run python examples/first.py
```

Кнопка **Run** в редакторе предназначена для подключённого хаба Pybricks.

## Добавить действие

Выберите строку, после которой нужно вставить действие. В Library откройте
`python/basics` и дважды нажмите `display`. Заполните `value`, например `123`.
Редактор вставит `print(123)` и приведёт отступы в порядок.

В Qt сниппет также можно перетащить из Library в программу. Пустое тело цикла
или условия обозначается `pass`. Вставка в эту позицию заменяет заглушку.

## Попробовать и отменить

**F2 / Edit as Python** открывает выбранный фрагмент для текстового редактирования.
Можно временно написать незаконченный код. Если Python не принимает результат,
диалог покажет причину и останется открытым. Основная программа ещё не изменена.
Исправьте текст или нажмите Cancel.

**Ctrl+Z** отменяет последнее изменение, включая перенос между программой
и Scratch. В Qt **Ctrl+Shift+Z**, в TUI **Ctrl+Y** возвращает отменённое изменение.

## Отложить фрагмент

Выделите действие и нажмите **Ctrl+X / To Scratch**. Оно исчезнет из программы
и появится справа. Если тело цикла опустело, редактор оставит `pass`.
В Scratch можно хранить даже текст, который пока не является программой.

Для возврата выберите место в программе, затем фрагмент Scratch и нажмите
**Restore at selection**. Код должен подходить к выбранному месту.

## Сохранить

**Ctrl+S** сохраняет программу как `.py`. Scratch сохраняется рядом в файле
`имя.py.pyblocks.json`. Этот дополнительный файл не нужен для запуска Python,
но его нужно переносить вместе с программой, если важны временные фрагменты.

Программу можно открыть в любом текстовом редакторе. Если её изменить там,
PyBlocks при следующем открытии заново построит структуру. Если файл изменён
внешним редактором уже после открытия, сохранение остановится с сообщением
о конфликте: откройте актуальную версию или сохраните свою под другим именем.
