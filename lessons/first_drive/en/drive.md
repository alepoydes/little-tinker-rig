# Your first journey

Place **Set up drive base** in the program. Keep motor ports **A / B**, set wheel diameter to **56 mm**, and axle track to **136 mm** (between wheel centers).

Add **Drive straight** and set the distance to **200 mm**. The library contains only these two blocks for this stage. Open the next hint if you get stuck; **Open starter program** opens setup code in a new program tab, keeping your current work.

Put the robot on clear floor, connect it and press **Run**. Measure the journey. If the robot reverses, check that left and right motors match the ports and the model's forward direction. Mark complete after the robot moves forward and stops.
