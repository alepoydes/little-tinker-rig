# Your first journey

Place **Set up a two-wheel robot** in the program. Keep motor ports **A / B**, set wheel diameter to **56 mm**, and axle track to **136 mm** (between wheel centers).

Add **Drive a distance, then stop** and set the distance to **200 mm**. The library contains only these two blocks for this stage. Open the next hint if you get stuck; **Apply starter program** provides setup only and is undoable.

Put the robot on clear floor, connect it and press **Run**. Measure the journey. If the robot reverses, check that left and right motors match the ports and the model's forward direction. Mark complete after the robot moves forward and stops.
