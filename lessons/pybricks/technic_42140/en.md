# 42140 · Transformation vehicle

<a name="prepare"></a>

## Prepare the model

Compare tank-style and car-style control when the vehicle flips.

Use LEGO **42140** and the exact mechanism from the source. A matching hub alone is not enough. The programs open as ordinary editable Python, recognized by the standard block library. The linked building instructions describe the model; this lesson opens without a 3D assembly view.

- [Video](https://www.youtube.com/watch?v=3Q0I79y1lC0)
No complete building guide is supplied by this upstream project; match its model before running.

Connect the required devices using the port tables in the following stages. Keep the original gearing, motor directions and calibration positions. Use current Pybricks firmware for your hub. These models need real hardware; the virtual hub does not simulate their mechanisms, remotes or balancing.

Open a program to inspect it before Run. Calibration can move motors immediately. Mark this stage complete when the mechanism and its connections are ready. Media links need internet; the lesson text, code and dependencies are included in saved projects.

## Try transformation

[Open `technic_42140_transformation.py`](program:technic_42140_transformation.py). This is your project copy; reopening it preserves your edits.

| Port | Python device | Code name |
|---|---|---|
| A | `Motor` | `right_motor` |
| B | `Motor` | `left_motor` |

Both variants handle flipping. The first remote layout controls each track separately and changes speed with the red buttons. The second uses left +/− for drive and right +/− for turning. Compare how each reads the hub orientation and changes motor commands.

Use Run to start this file and Stop to finish. Compare what you predicted with the robot’s behavior before marking the stage complete.
