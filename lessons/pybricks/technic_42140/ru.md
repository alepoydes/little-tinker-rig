# 42140 · Машина-перевёртыш

<a name="prepare"></a>

## Подготовь модель

Сравни гусеничное и автомобильное управление при перевороте машины.

Нужны LEGO **42140** и точный механизм из исходного проекта. Одного подходящего хаба недостаточно. Программы открываются как обычный редактируемый Python со стандартными блоками. Модель показана в инструкции по ссылке; этот урок открывается без режима пошаговой 3D-сборки.

- [Видео](https://www.youtube.com/watch?v=3Q0I79y1lC0)
В исходном проекте нет полной инструкции сборки; до запуска нужна соответствующая модель.

Подключи устройства по таблицам портов следующих этапов. Сохрани передачи, направления моторов и исходные положения калибровки. Используй актуальную прошивку Pybricks для своего хаба. Нужен настоящий робот: виртуальный хаб не моделирует эти механизмы, пульты и равновесие.

Перед запуском открой и изучи программу. Калибровка может сразу двигать моторы. Отметь этап, когда механизм и подключения готовы. Ссылки на медиа требуют сети; текст, код и зависимости входят в сохранённый проект.

Источники: [index.md](https://github.com/pybricks/pybricks-projects/blob/faaacce09ffe1d865fd1db241bcacb056234d597/sets/technic/42140-app-controlled-transformation-vehicle/powered-up-remote/index.md). Geoff Stearns. [MIT](LICENSE.txt).

## Попробуй: управление гусеницами

| Порт | Устройство Python | Имя в коде |
|---|---|---|
| A | `Motor` | `right_motor` |
| B | `Motor` | `left_motor` |

Оба варианта учитывают переворот. В первом каждая сторона пульта управляет своей гусеницей, красные кнопки меняют скорость. Во втором левые +/− задают движение, правые +/− — поворот. Сравни чтение ориентации хаба и изменение команд моторам.

Кнопка «Запуск» запускает этот файл, «Остановить» завершает его. Сравни прогноз с поведением робота, затем отметь выполнение.
