# 42131 · Бульдозер CAT D11

<a name="prepare"></a>

## Подготовь модель

Управляй гусеницами и навесными механизмами с пульта.

Нужны LEGO **42131** и точный механизм из исходного проекта. Одного подходящего хаба недостаточно. Программы открываются как обычный редактируемый Python со стандартными блоками. Модель показана в инструкции по ссылке; этот урок открывается без режима пошаговой 3D-сборки.

- [Видео](https://www.youtube.com/watch?v=N7OmW-7u8fA)
- [Инструкция сборки](https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6403271.pdf)
- [Инструкция сборки](https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6403276.pdf)
- [Видео](https://www.youtube.com/watch?v=gy3nFvojZ2o)

Подключи устройства по таблицам портов следующих этапов. Сохрани передачи, направления моторов и исходные положения калибровки. Используй актуальную прошивку Pybricks для своего хаба. Нужен настоящий робот: виртуальный хаб не моделирует эти механизмы, пульты и равновесие.

Перед запуском открой и изучи программу. Калибровка может сразу двигать моторы. Отметь этап, когда механизм и подключения готовы. Ссылки на медиа требуют сети; текст, код и зависимости входят в сохранённый проект.

## Попробуй: пульт

[Открой `technic_42131_bulldozer.py`](program:technic_42131_bulldozer.py). Это копия в твоём проекте; повторное открытие сохраняет изменения.

| Порт | Устройство Python | Имя в коде |
|---|---|---|
| A | `Motor` | `left_motor` |
| B | `Motor` | `right_motor` |
| C | `Motor` | `function_motor` |
| D | `Motor` | `switch_motor` |

До запуска изучи кнопки и положения коробки передач. Проверь каждый механизм отдельно, затем измени одну рабочую скорость и сравни реакцию.

Кнопка «Запуск» запускает этот файл, «Остановить» завершает его. Сравни прогноз с поведением робота, затем отметь выполнение.

### Разбери код

Найди создание устройств, затем последовательность действий или цикл управления. Читай комментарии к выбранной программе и меняй один параметр за раз. Библиотека содержит блоки этой программы; «Показать все блоки» снимает ограничение для свободного опыта. Подробное авторское объяснение на английском доступно по ссылке «Источники» ниже.
