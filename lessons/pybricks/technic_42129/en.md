# 42129 · Zetros trial truck

<a name="prepare"></a>

## Prepare the model

Drive the truck and switch its differential lock.

Use LEGO **42129** and the exact mechanism from the source. A matching hub alone is not enough. The programs open as ordinary editable Python, recognized by the standard block library. The linked building instructions describe the model; this lesson opens without a 3D assembly view.

- [Video](https://www.youtube.com/watch?v=-YuvEUQPGnM)
- [Building instructions](https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6381993.pdf)

Connect the required devices using the port tables in the following stages. Keep the original gearing, motor directions and calibration positions. Use current Pybricks firmware for your hub. These models need real hardware; the virtual hub does not simulate their mechanisms, remotes or balancing.

Open a program to inspect it before Run. Calibration can move motors immediately. Mark this stage complete when the mechanism and its connections are ready. Media links need internet; the lesson text, code and dependencies are included in saved projects.

## Try zetros

[Open `technic_42129_zetros.py`](program:technic_42129_zetros.py). This is your project copy; reopening it preserves your edits.

| Port | Python device | Code name |
|---|---|---|
| A | `Motor` | `drive_motor1` |
| B | `Motor` | `drive_motor2` |
| C | `DCMotor` | `lock_motor` |
| D | `Motor` | `steer_motor` |

The center remote button toggles the differential lock. Compare turning with the lock enabled and disabled at low speed. Explain the difference before changing the program.

Use Run to start this file and Stop to finish. Compare what you predicted with the robot’s behavior before marking the stage complete.
