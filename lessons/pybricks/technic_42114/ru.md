# 42114 · Самосвал Volvo

<a name="prepare"></a>

## Подготовь модель

Исследуй руление, разгрузку и автоматическое/ручное переключение передач.

Нужны LEGO **42114** и точный механизм из исходного проекта. Одного подходящего хаба недостаточно. Программы открываются как обычный редактируемый Python со стандартными блоками. Модель показана в инструкции по ссылке; этот урок открывается без режима пошаговой 3D-сборки.

- [Видео](https://www.youtube.com/watch?v=j4ZxOhXygNY)
- [Инструкция сборки](https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6396116.pdf)

Подключи устройства по таблицам портов следующих этапов. Сохрани передачи, направления моторов и исходные положения калибровки. Используй актуальную прошивку Pybricks для своего хаба. Нужен настоящий робот: виртуальный хаб не моделирует эти механизмы, пульты и равновесие.

Перед запуском открой и изучи программу. Калибровка может сразу двигать моторы. Отметь этап, когда механизм и подключения готовы. Ссылки на медиа требуют сети; текст, код и зависимости входят в сохранённый проект.

## Попробуй: самосвал

[Открой `technic_42114_hauler.py`](program:technic_42114_hauler.py). Это копия в твоём проекте; повторное открытие сохраняет изменения.

| Порт | Устройство Python | Имя в коде |
|---|---|---|
| A | `Motor` | `drive` |
| B | `Motor` | `self.gearbox` |
| D | `Motor` | `steer` |

Зелёная кнопка переключает автоматический и ручной режим. В ручном красные кнопки меняют передачи. В автоматическом правая красная включает разгрузку, левая возвращает движение. Наблюдай индикатор пульта и меняй только один порог коробки.

Кнопка «Запуск» запускает этот файл, «Остановить» завершает его. Сравни прогноз с поведением робота, затем отметь выполнение.

### Разбери код

Найди создание устройств, затем последовательность действий или цикл управления. Читай комментарии к выбранной программе и меняй один параметр за раз. Библиотека содержит блоки этой программы; «Показать все блоки» снимает ограничение для свободного опыта. Подробное авторское объяснение на английском доступно по ссылке «Источники» ниже.
