# 42124 · Off-Road Buggy

<a name="prepare"></a>

## Prepare the model

Center steering and drive using a Powered Up remote.

Use LEGO **42124** and the exact mechanism from the source. A matching hub alone is not enough. The programs open as ordinary editable Python, recognized by the standard block library. The linked building instructions describe the model; this lesson opens without a 3D assembly view.

- [Video](https://www.youtube.com/watch?v=6Urq0aX2jR4)
- [Building instructions](https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6351188.pdf)

Connect the required devices using the port tables in the following stages. Keep the original gearing, motor directions and calibration positions. Use current Pybricks firmware for your hub. These models need real hardware; the virtual hub does not simulate their mechanisms, remotes or balancing.

Open a program to inspect it before Run. Calibration can move motors immediately. Mark this stage complete when the mechanism and its connections are ready. Media links need internet; the lesson text, code and dependencies are included in saved projects.

### Upstream explanation (MIT)

The following licensed notes describe the original workflow. Program links above open the adapted Studio copies; installation and terminal names may refer to Pybricks Code.

In this project we'll show you how to control the Technic Off-Road buggy with
the Powered Up remote.

### Program

This program is similar to most driving vehicles in the Technic series. Check
out the [Technic X-treme Off-Roader](https://github.com/pybricks/pybricks-projects/blob/faaacce09ffe1d865fd1db241bcacb056234d597/sets/technic/42099-off-roader/index.md) examples for
additional tips and tricks.

When the program starts, it connects to your remote and the steering mechanism
is calibrated. Then you are ready to drive.

The left channel controls the steering and right channel drives the car.
