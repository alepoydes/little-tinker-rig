# Pybricks website examples

These programs come from the downloadable Python projects and inline Python
examples on [Pybricks](https://pybricks.com/project/). The project pages credit
Laurens Valk. The website copyright notice names Laurens Valk and David Lechner.

The website's [content terms](https://pybricks.com/legal/#pybricks-website-site-content)
apply to these sources. The MIT license in the parent directory covers imports
from the separate Pybricks Projects repository; it does not relicense website
content. Retain this notice and the original source links when using these files.

[The main catalog](../catalog.json) records each program's source URL, SHA-256,
hardware requirements and adaptations. [The website inventory](catalog.json)
also lists excluded downloads and their reasons. Downloads were retrieved on
2026-09-26. Editor metadata headers are removed; executable code and explanatory
comments are retained. `InventorHub` is updated to the `PrimeHub` alias.

Two menu programs are extracted from the Python listings on the hub-menu page;
their hashes cover the extracted Python text. The existing 42109 Xbox example
remains the MIT adaptation in the parent directory and is linked by the inventory
instead of being duplicated here.
